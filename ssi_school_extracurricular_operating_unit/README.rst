=========================================
School Extracurricular + Operating Unit
=========================================

Adds Operating Unit (OU) support to the extracurricular Offering and
Participant documents, restricts their visibility per operating unit, and
propagates the participant's operating unit onto the fee lines and invoice
it generates (Route A addendum lines and the Route B consolidated
invoice).


Work Instruction
================

* `Create Extracurricular Offering <docs/school_extracurricular_offering/index.html>`_
* `Create Extracurricular Participant <docs/school_extracurricular_participant/index.html>`_
* `Create Due Invoice - Extracurricular <docs/school_extracurricular_create_due_invoice/index.html>`_


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-extracurricular
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *School Extracurricular + Operating Unit*
6.  Install the module
